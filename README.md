# Pengaruh Aktivitas Pengembangan CV terhadap Tingkat Stres Mahasiswa di Institut Teknologi Sains Bandung

Laporan survei mata kuliah **Teknik Sampling dan Survei** — Program Studi S1 Sains Data, Institut Teknologi Sains Bandung (Semester 2).

> Dosen Pengampu: Dr. Andi Pujo Rahadi, S.T., M.Sc.
> Kelompok 3 · Metode Sampling: Purposive Sampling

## Latar Belakang

Mahasiswa semester awal sering dihadapkan pada tekanan untuk mempersiapkan CV yang kompetitif (organisasi, magang, lomba, pelatihan) di tengah beban akademik yang tinggi. Penelitian ini menguji apakah tekanan pengembangan CV berkaitan dengan tingkat stres mahasiswa.

## Tujuan Penelitian

1. Mengidentifikasi profil demografis responden
2. Mengukur tingkat tekanan CV (skala Likert 1–5)
3. Mengukur tingkat stres mahasiswa terkait persiapan karier
4. Menghitung korelasi Pearson antara CV Score dan Stress Score
5. Menyajikan hasil dalam bentuk visualisasi
6. Menarik kesimpulan sebagai masukan bagi program bimbingan mahasiswa

## Metodologi

| Aspek | Keterangan |
|---|---|
| Populasi | ± 1.000 mahasiswa aktif ITSB |
| Metode Sampling | Purposive Sampling |
| Jumlah Sampel (Rumus Slovin, e=15%) | ± 43 responden |
| Responden Aktual | 36 mahasiswa |
| Instrumen | Kuesioner Google Form, skala Likert 1–5 |
| Variabel | CV Score (7 item) dan Stress Score |

## Temuan Utama

- Korelasi positif kuat dan signifikan antara tekanan CV dan stres mahasiswa: **r = 0.71, p < 0.001**
- Rata-rata CV Score = **3.56/5**, tekanan tertinggi pada kekhawatiran minimnya pengalaman organisasi dan antisipasi rekrutmen
- Item kecemasan masa depan karier memiliki skor tertinggi (**4.19/5**)
- ~28% responden belum pernah membuat CV namun tetap merasakan tekanan tinggi → tekanan bersifat antisipatif, bukan reaktif
- **r² ≈ 0.50** → tekanan CV menjelaskan sekitar 50% variasi stres; sisanya dipengaruhi faktor lain (akademik, keluarga, finansial, psikologis)
